# سِجِلّ — سجل متابعة الطلاب

تطبيق عربي متجاوب للمعلم **أحمد متولي سعد متولي**، مبني باستخدام Next.js وPostgreSQL وDrizzle ORM.

## الاستخدام

- اختر الفصل، ثم أدخل الدرجات مباشرة في الجدول. الاختبارات القصيرة من 5، والمشاركة والواجبات والأنشطة الصفية والمهام الأدائية من 1.
- تُحفظ التعديلات محليًا في المتصفح، وتُزامَن تلقائيًا مع PostgreSQL. يظهر تنبيه واضح إذا تعذرت المزامنة؛ تبقى النسخة المحلية متاحة على الجهاز.
- يتيح زر **حفظ الدرجات** حفظ التغييرات وإنشاء نسخة مؤرشفة يمكن استرجاعها من «السجلات المحفوظة».
- يمكن البحث عن الطلاب، تصفية الأسابيع، تعديل الأسماء، وإضافة الطلاب وحذفهم.
- اضغط **أسبوع جديد** أو أيقونة التقويم لإنشاء جدول لأي أسبوع من 1 إلى 40، مثل الأسبوع الثاني عشر. اختر الفصل الحالي أو جميع الفصول؛ يبدأ الجدول بخانات فارغة دون تغيير درجات الأسابيع السابقة.
- ارفع شعار أعلى يمين الترويسة وشعار أعلى اليسار من خانتَي الرفع فوق الجدول، أو من الإعدادات. يدعم السحب والإفلات وPNG وJPG وWebP حتى 5 ميجابايت. تُصغّر الصور تلقائيًا مع الحفاظ على الشفافية، وتُحفظ في قاعدة البيانات وذاكرة المتصفح.
- اضغط **الملء التلقائي** لملء أسبوع محدد أو جميع الأسابيع، في الفصل الحالي أو جميع الفصول. اختر الدرجة الكاملة، أو درجات مخصصة لكل بند، أو نسخ درجات أسبوع مرجعي. الوضع الافتراضي يملأ الفراغات فقط ولا يغيّر الصفر؛ الاستبدال يتطلب تأكيدًا ويعرض عدد الخانات ومعاينة قبل التنفيذ. يتوفر زر للتراجع عن آخر ملء خلال الجلسة، مع تجاهل القيم التي عُدّلت يدويًا بعد الملء. راجع الدرجات المقترحة قبل اعتماد السجل.
- زر **الاختبارات العشوائية** منفصل عن الملء العام: يوزع درجات الاختبارات القصيرة فقط من 0 إلى 5. عند تفعيل مراعاة السجل السابق، يحسب متوسط اختبارات الطالب في الأسابيع الأقدم بوزن أكبر للأسابيع الأحدث، ثم يختار درجة قريبة منه بفارق يصل إلى درجة واحدة؛ دون سجل سابق يكون التوزيع منتظمًا من 0 إلى 5. يعرض معاينة ويمكن إعادة الاقتراح قبل الحفظ. هذه قيم مقترحة وليست تقييمًا فعليًا، ويجب مراجعتها قبل الاعتماد.
- زر **إكمال البنود الأخرى** يملأ المشاركة والواجبات والأنشطة الصفية والمهام الأدائية بالدرجة الكاملة 1 دفعة واحدة، دون تغيير الاختبارات القصيرة. الافتراضي ملء الفراغات فقط، مع خيار مؤكد للاستبدال. كلا الزرين يدعمان أسبوعًا محددًا أو جميع الأسابيع، والفصل الحالي أو جميع الفصول، والحفظ التلقائي والتراجع عن آخر إدخال خلال الجلسة.
- **خيارات الطباعة** توفر ثلاثة أزرار منفصلة: طباعة جميع الفصول لأسبوع أو عدة أسابيع تختارها، وطباعة جميع الفصول لجميع الأسابيع دفعة واحدة، وطباعة فصل محدد مع أسبوع أو عدة أسابيع. تعرض عدد الصفحات قبل المعاينة. **تصدير PDF** ينزّل ملف A4 أفقيًا بخطوط عربية والشعارات المرفوعة والتوقيعات؛ وتُقسّم الأسابيع إلى أربعة أسابيع في كل صفحة مع تكرار الترويسة.
- تعرض شاشة التقارير عدد الطلاب ومتوسط الدرجات والدرجة القصوى ونسبة اكتمال الرصد الفعلية، محسوبة حسب أسابيع كل فصل.
- من الإعدادات يمكن تعديل الشعارات واسم المعلم والمدرسة والعام الدراسي وتنزيل نسخة احتياطية JSON لجميع البيانات.

## البيانات الأولية

تم إدخال أسماء ودرجات الفصول السبعة الفريدة من الصور المرفقة، بإجمالي 131 طالبًا، للأسابيع الثامن والتاسع والعاشر والحادي عشر. لم تُكرر الصفحات الموجودة أكثر من مرة في الصور. البيانات قابلة للتعديل، ويُنصح بمراجعتها قبل الاعتماد النهائي. الترويسة أُعيد رسمها بتنسيق مدرسي، وليست صورة مسحًا ضوئيًا للأصل.

## التشغيل المحلي

1. تثبيت الاعتماديات: `npm install`.
2. ضبط `DATABASE_URL` في `.env` إلى اتصال PostgreSQL صالح.
3. تطبيق الجداول: `npx drizzle-kit push`.
4. التطوير: `npm run dev`، أو الإنتاج: `npm run build` ثم `npm run start`.

تُنشأ البيانات الأولية تلقائيًا عند أول طلب ناجح إلى `/api/workspace`، دون استبدال السجلات المحفوظة سابقًا. جميع استعلامات قاعدة البيانات تستخدم Drizzle. المنطق الخاص بالاتصال موجود في `src/db/index.ts`، والجداول في `src/db/schema.ts`.

## الفحص

- `npm run lint`
- `npx next typegen`
- `npm exec tsc -- --noEmit`
- `npm run build`

يوجد اختبار متصفح في `scripts/verify.mjs`، واختبار للشعارات والجداول الأسبوعية في `scripts/verify-features.mjs`. يتطلبان تشغيل التطبيق مسبقًا وتثبيت Chromium باستخدام `npx playwright install chromium`، ثم تشغيل `node scripts/verify.mjs` و`node scripts/verify-features.mjs` و`node scripts/verify-autofill.mjs` و`node scripts/verify-quick-fill.mjs`. اختبارات الميزات الجديدة تستعيد الفصول والأسابيع والدرجات والشعارات الأصلية بعد انتهائها. يستخدم عنوان `http://localhost:3000`، ويغطي الحفظ وإعادة التحميل وإدارة الطلاب وPDF والعرض على الهاتف. **يُشغّل على قاعدة بيانات اختبارية فقط**؛ إذ يضيف طالبًا مؤقتًا ودرجات اختبار ثم يعيد الحالة الأصلية وينظف النسخ التي أنشأها أثناء الاختبار.

## ملاحظات الحفظ

النسخة المحلية خاصة بالمتصفح المستخدم وليست بديلًا عن النسخ الاحتياطي. لا تمسح بيانات الموقع قبل تنزيل نسخة احتياطية إذا كانت هناك تعديلات لم تُزامَن. الأرشيف يحفظ آخر 50 نسخة يدوية، ولا يحدّ من حفظ الدرجات نفسها. لا توجد مصادقة مستخدمين في هذه النسخة؛ فهي مساحة عمل لمعلم واحد، ويلزم إضافة التحكم في الوصول قبل نشر بيانات الطلاب على نطاق عام.
